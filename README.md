# dashboard_mmb — конструктор отчетности ММБ

Статический сайт: `index.html` — конструктор, `check.html` — проверка связи с базой. Хостинг: GitVerse Pages (или GitHub Pages). Данные хранятся в Supabase, код страниц данных не содержит.

## Как включить общую базу (Supabase)

1. **Таблицы.** Supabase → SQL Editor → New query → вставить `supabase/setup.sql` → Run.
2. **Ключи.** Supabase → Project Settings → API: скопировать *Project URL* и *anon (publishable) key* и вписать их в файл `config.js` в корне репозитория (прямо в веб-интерфейсе GitVerse: открыть файл → ✎ → сохранить). Пользователям ничего вводить не нужно. Ключ `service_role` никуда не вставлять.
3. **Вход только для своих.** Authentication → Sign In / Providers → выключить «Allow new users to sign up». Пользователей добавлять вручную: Authentication → Users → Add user (почта + пароль, «Auto confirm»).
4. **Роли.** Для каждого пользователя в SQL Editor:
   ```sql
   insert into public.members (user_id, role, name)
   select id, 'editor', 'Фамилия И.' from auth.users where email = 'почта@...';
   -- 'editor' — загружает и правит, 'viewer' — только смотрит
   ```
5. **Проверка из корпоративной сети.** Открыть `https://<owner>.gitverse.site/dashboard_mmb/check.html` на рабочем ноутбуке → «Проверить» (почта/пароль — по желанию, для проверки входа). Пункты 1–4 должны быть зелеными.
6. **Работа.** В конструкторе «☁ Войти в облако» → почта и пароль. Если в облаке пусто, конструктор предложит загрузить туда дайджесты из браузера.

## Как устроено
- Один дайджест = одна строка `digests` (jsonb со всем состоянием: отчеты, данные, графики, презентация, версии). Excel не хранится — только разобранные таблицы. Личные настройки экрана (открытая страница, фильтры) остаются в браузере.
- Сохранение — через 2 с после правки; другие пользователи получают обновление сразу (Realtime) или опросом раз в 30 с, если websocket закрыт прокси.
- Защита от затирания: у строки есть номер правки `rev`. Если коллега сохранил раньше, конструктор покажет выбор «взять версию коллеги / сохранить мою поверх».
- Права — политики RLS в базе: без входа данных не видно, viewer только читает.

## Ограничения
- Бесплатный проект Supabase засыпает после 7 дней без запросов.
- GitVerse Pages требует публичный репозиторий: код виден всем, данных в нем нет.
- GigaChat нельзя вызывать прямо из браузера (секретный ключ, CORS) — нужен посредник: Supabase Edge Function. Следующий этап.
